## 📝 Documentation Standards

### ✅ Required Format
- Actual data (no placeholders like [VALUE] or [XX])
- Timestamps (YYYY-MM-DD HH:MM UTC format)
- Tool versions documented
- Source URLs for all claims
- Screenshots and evidence files

### 🎯 Success Criteria
- All metrics use specific numerical values
- All tests timestamped
- Test conditions documented
- Raw data exports included
