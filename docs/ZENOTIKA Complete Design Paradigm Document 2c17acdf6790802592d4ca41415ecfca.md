# SECTION I: GLOSSARY

┌─────────────────────────────────────────────────────────────────────────────┐
│                                                                             │
│  GLOSSARY                                                                   │
│  ════════                                                                   │
│                                                                             │
│  Untuk menghindari ambiguitas, berikut definisi istilah dalam dokumen:     │
│                                                                             │

│  │                                                                      │  │
│  │  GENERAL TERMS                                                       │  │
│  │  ─────────────                                                       │  │
│  │                                                                      │  │
│  │  Paradigm                                                            │  │
│  │  : Pola pikir, pendekatan, dan prinsip visual yang menjadi acuan.    │  │
│  │    Bukan template yang harus di-copy, melainkan filosofi yang       │  │
│  │    harus dipahami dan diadaptasi.                                    │  │
│  │                                                                      │  │
│  │  Identical                                                           │  │
│  │  : Mengikuti paradigm yang sama, BUKAN menyalin visual persis.      │  │
│  │    Hasil akhir harus terasa "sekeluarga" dengan reference,          │  │
│  │    bukan "kembar identik".                                          │  │
│  │                                                                      │  │
│  │  Immersive                                                           │  │
│  │  : Pengalaman yang membuat user merasa "masuk" ke dalam dunia       │  │
│  │    digital, bukan sekedar melihat layar.                            │  │
│  │                                                                      │  │
│  │  Visual-First                                                        │  │
│  │  : Pendekatan dimana informasi utama disampaikan melalui visual     │  │
│  │    (gambar, animasi, 3D), dengan teks sebagai pendukung.            │  │
│  │                                                                      │  │
│  │  Scroll-Driven                                                       │  │
│  │  : Interaksi dan animasi yang dipicu/dikontrol oleh scroll user.    │  │
│  │                                                                      │  │
│  │                                                                      │  │
│  │  ZENOTIKA-SPECIFIC TERMS                                             │  │
│  │  ───────────────────────                                             │  │
│  │                                                                      │  │
│  │  Sphere                                                              │  │
│  │  : Fitur yang menampilkan perjalanan personal user dalam bentuk     │  │
│  │    3D explorable space.  Berisi milestones, foto kenangan,           │  │
│  │    achievements, dan reflections.                                   │  │
│  │                                                                      │  │
│  │  Futures                                                             │  │
│  │  : Fitur assessment/questionnaire untuk menentukan gaya belajar     │  │
│  │    user berdasarkan Kolb's Learning Style Inventory.                │  │
│  │                                                                      │  │
│  │  Milestone                                                           │  │
│  │  : Titik pencapaian dalam perjalanan user (semester, periode,       │  │
│  │    achievement tertentu).                                           │  │
│  │                                                                      │  │
│  │  Room                                                                │  │
│  │  : Ruang virtual dalam Sphere yang merepresentasikan satu           │  │
│  │    milestone atau kategori konten.                                  │  │
│  │                                                                      │  │
│  │  Portal                                                              │  │
│  │  : Elemen transisi antara rooms dalam Sphere.                       │  │
│  │                                                                      │  │
│  │                                                                      │  │
│  │  TECHNICAL TERMS                                                     │  │
│  │  ───────────────                                                     │  │
│  │                                                                      │  │
│  │  WebGL                                                               │  │
│  │  : Web Graphics Library.  API untuk rendering grafis 2D/3D           │  │
│  │    di browser tanpa plugin.                                         │  │
│  │                                                                      │  │
│  │  Three.js                                                            │  │
│  │  : Library JavaScript untuk membuat dan menampilkan grafis 3D       │  │
│  │    menggunakan WebGL.                                               │  │
│  │                                                                      │  │
│  │  GSAP                                                                │  │
│  │  : GreenSock Animation Platform. Library untuk animasi              │  │
│  │    high-performance di web.                                         │  │
│  │                                                                      │  │
│  │  ScrollTrigger                                                       │  │
│  │  : Plugin GSAP untuk membuat animasi yang dipicu oleh scroll.       │  │
│  │                                                                      │  │
│  │  Lenis                                                               │  │
│  │  : Library untuk smooth scrolling yang terasa natural.              │  │
│  │                                                                      │  │
│  │  GLSL                                                                │  │
│  │  : OpenGL Shading Language. Bahasa untuk menulis shader             │  │
│  │    (program yang berjalan di GPU untuk efek visual).                │  │
│  │                                                                      │  │
│  │  Post-processing                                                     │  │
│  │  : Efek visual yang diterapkan setelah scene 3D di-render           │  │
│  │    (bloom, blur, color grading, dll).                               │  │
│  │                                                                      │  │
│  │  Hotspot                                                             │  │
│  │  : Titik interaktif pada objek 3D yang dapat diklik untuk           │  │
│  │    menampilkan informasi tambahan.                                  │  │
│  │                                                                      │  │
│  │  Parallax                                                            │  │
│  │  : Efek dimana elemen bergerak dengan kecepatan berbeda             │  │
│  │    berdasarkan "kedalaman" untuk menciptakan ilusi 3D.               │  │
│  │                                                                      │  │
│  │  God Rays                                                            │  │
│  │  : Efek visual berupa sinar cahaya yang terlihat menembus           │  │

│  │                                                                      │  │
│  │  Chromatic Aberration                                                │  │
│  │  : Efek visual dimana warna "terpisah" sedikit, seperti pada        │  │
│  │    lensa kamera.  Sering digunakan untuk kesan dinamis/speed.        │  │
