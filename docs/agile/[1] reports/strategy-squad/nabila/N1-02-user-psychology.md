## Scroll Psychology

### Scroll as Interaction Metaphor

**Why Scrolling Works:**
```yaml
Familiarity: Universal gesture (mobile + desktop)
Control: User-paced navigation
Discovery: Curiosity-driven exploration
Flow: No disruptive clicks/page loads
```

**ScrollTrigger Psychology:**
- **Anticipation:** User knows more content awaits
- **Reward:** New visuals/info revealed per scroll
- **Progression:** Clear forward movement
- **Mastery:** User feels in control

## Progressive Disclosure

### Information Architecture

**Cognitive Load Management:**
```
Chapter 1: "Science" (Foundation)
  ├─ What: Corn genetics
  ├─ Why: Innovation matters
  └─ Hook: Visual wow factor

Chapter 2: "Testing" (Validation)
  ├─ How: Real-world application
  ├─ Proof: Farmer results
  └─ Trust: Social proof

Chapter 3: "Result" (Action)
  ├─ Impact: Business metrics
  ├─ Benefit: Clear value prop
  └─ CTA: Next steps
```

**Miller's Law:** 7±2 chunks → Each chapter has 5-7 key points

## Motivation Drivers (Fogg Behavior Model)

### B = MAT (Behavior = Motivation × Ability × Trigger)

**Motivation (High):**
- Desire for innovation (business goal)
- Curiosity about technology (personal interest)
- Social validation (peers/competitors viewing)

**Ability (Easy):**
- Simple scroll interaction  
- No learning curve
- Responsive design (works everywhere)

**Trigger (Present):**
- Visual cues (arrows, animations)
- Progressive scroll hints
- Compelling initial view

**Result:** High conversion likelihood when all 3 align
