### NPV Calculator

```javascript
// ILLUSTRATIVE EXAMPLE - NPV Calculation

function calculateNPV(initialInvestment, cashFlows, discountRate) {
  let npv = -initialInvestment;
  
  cashFlows.forEach((cashFlow, year) => {
    npv += cashFlow / Math.pow(1 + discountRate, year + 1);
  });
  
  return npv;
}

// Example usage
const investment = 150000; // $150K
const annualBenefit = 80000; // $80K/year
const years = 3;
const discountRate = 0.10; // 10%

const cashFlows = Array(years).fill(annualBenefit);
const npv = calculateNPV(investment, cashFlows, discountRate);

console.log(`NPV: $${npv.toLocaleString()}`);
// NPV: $48,947 (positive = worthwhile investment)
```

## ✅ Usage Checklist

### Before Presenting Business Case

- [ ] All financial projections reviewed by finance
- [ ] Technical feasibility validated by engineering
- [ ] Market benchmarks verified with sources
- [ ] Risk assessment reviewed by stakeholders
- [ ] Executive summary is compelling and concise
- [ ] Supporting data is accurate and sourced

### Common Objections & Responses

| Objection | Response |
|-----------|----------|
| "Too expensive" | Show ROI timeline, compare to alternatives |
| "Risky technology" | Cite browser support stats (98.5%), progressive enhancement |
| "Can't measure results" | Present analytics implementation plan |
| "Takes too long" | Compare to native app timeline, show phased approach |
| "Our audience doesn't care" | Present competitor analysis, user research |
