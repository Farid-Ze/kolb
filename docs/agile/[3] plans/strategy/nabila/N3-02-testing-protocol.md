## 🧪 USABILITY TESTING PROTOCOL

### Pre-Test Preparation

#### Screening Questionnaire
```
1. How often do you browse websites with interactive 3D content?
   [ ] Never [ ] Rarely [ ] Sometimes [ ] Often [ ] Very often

2. What device do you primarily use for web browsing?
   [ ] Desktop/Laptop [ ] Tablet [ ] Mobile phone

3. How would you rate your comfort with technology? (1-5)
   [ ] 1 [ ] 2 [ ] 3 [ ] 4 [ ] 5

4. Have you purchased agricultural products online before?
   [ ] Yes [ ] No

5. What is your age range?
   [ ] 18-24 [ ] 25-34 [ ] 35-44 [ ] 45-54 [ ] 55+
```

- [ ] Consent form signed

### Moderation Script

```markdown
## Introduction (5 minutes)

"Thank you for participating today. I'm [Name], and I'll be guiding you through this session.

We're testing a website, not you - there are no wrong answers. We want to understand how real people interact with this experience.

Please think aloud as you navigate - tell me what you're thinking, what you expect, and any confusion you have.

This session will take about 45 minutes. Do you have any questions before we begin?"

## Warm-up Task

"Before we start, please tell me about the last time you explored an interactive website. What made it memorable?"

## Task Scenarios

[Proceed with numbered tasks below]

## Post-Task Questions

"Now that you've explored the site, I have a few questions..."

## Closing (5 minutes)

"Thank you for your time. Your feedback is incredibly valuable. Do you have any final thoughts or questions?"
```

### Task Scenarios

```markdown
### Task 1: First Impressions (Exploratory)
"I'd like you to explore this website as you naturally would. Please tell me what catches your attention and what you think this site is about."

Success Criteria:
- User identifies the brand/product within 30 seconds
- User attempts to scroll or interact
- User can articulate the value proposition

Observe:
- Where does their eye go first?
- Do they scroll immediately or wait?
- What questions do they verbalize?

---

### Task 2: Navigation (Goal-Directed)
"Imagine you're interested in learning more about this product. Please find information about how it works."

Success Criteria:
- User finds relevant section within 60 seconds
- User uses scroll or navigation elements
- User understands content

Observe:
- Do they use scroll or navigation links?
- Do they get lost?
- Is the information hierarchy clear?

---

### Task 3: Conversion Intent
"Suppose you wanted to get in touch with the company. How would you do that?"

Success Criteria:
- User finds contact form within 30 seconds
- User understands how to complete form
- No confusion about required fields

Observe:
- Path to conversion
- Hesitation points
- Trust concerns

---

### Task 4: Mobile Experience (if applicable)
"Now let's view the same site on a mobile device. Please complete the same exploration you did before."

Success Criteria:
- User can navigate successfully
- Touch interactions work as expected
- Content remains readable

Observe:
- Touch accuracy
- Gesture recognition
- Content legibility

---

### Task 5: Return Visit Scenario
"Imagine you visited this site yesterday. What do you remember? What would make you come back?"

Success Criteria:
- User recalls key brand elements
- User can articulate memorable moments
- User expresses intent to return

Observe:
- What stuck with them?
- What would they tell a friend?
```

## 🔬 A/B TESTING PLAN

### Test 1: CTA Placement

| Variant | Description | Hypothesis |
|---------|-------------|------------|
| Control | CTA at hero + end | Baseline |
| A | Floating CTA after 20% scroll | Higher visibility → +10% clicks |
| B | Multiple inline CTAs | More opportunities → +15% clicks |

### Test 2: Loading Experience

| Variant | Description | Hypothesis |
|---------|-------------|------------|
| Control | Spinner only | Baseline |
| A | Progress bar + tips | Reduced perceived wait → -20% bounce |
| B | Animated preview | Excitement building → -25% bounce |

### Test 3: Content Pacing

| Variant | Description | Hypothesis |
|---------|-------------|------------|
| Control | Linear scroll | Baseline |
| A | Faster reveals | Shorter attention → +10% completion |
| B | Interactive checkpoints | Engagement → +15% completion |

### Statistical Requirements

```
Sample Size Calculator:

For 95% confidence, 80% power, detecting 10% difference:
- Baseline CVR: 3.5%
- Minimum detectable effect: 10% relative (0.35% absolute)
- Required sample: ~10,000 per variant

Duration Estimate:
- Daily traffic: 1,000 visitors
- Time for 10,000/variant with 2 variants: ~20 days
- Recommend 3-4 weeks to account for variability
```

## 📊 DATA COLLECTION METHODS

### Quantitative Data

```javascript
// User testing analytics
const userTestingTracker = {
  trackTaskStart(taskId) {
    this.startTime = Date.now();
    analytics.track('test_task_start', { taskId });
  },
  
  trackTaskComplete(taskId, success) {
    const duration = Date.now() - this.startTime;
    analytics.track('test_task_complete', {
      taskId,
      success,
      duration,
      errors: this.errorCount
    });
  },
  
  trackError(taskId, errorType) {
    this.errorCount = (this.errorCount || 0) + 1;
    analytics.track('test_task_error', { taskId, errorType });
  },
  
  trackScrollDepth(depth) {
    analytics.track('test_scroll_depth', { depth });
  }
};
```
