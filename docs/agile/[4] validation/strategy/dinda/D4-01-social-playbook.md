## 📱 SOCIAL MEDIA PLAYBOOK

### 1. Platform Strategy Overview

#### Platform Selection Matrix

| Platform | Best For | Content Type | Frequency |
|----------|----------|--------------|-----------|
| LinkedIn | B2B, professional | Articles, demos | 3-5x/week |
| Twitter/X | Quick updates, tech | Short video, GIFs | Daily |
| Instagram | Visual showcase | Stories, Reels | 4-5x/week |
| YouTube | Long-form, tutorials | Demos, BTS | 1-2x/week |
| TikTok | Viral, younger B2B | Short-form | 3-5x/week |

### 3. Platform-Specific Guidelines

#### LinkedIn

| Element | Specification |
|---------|---------------|
| Video length | 1-3 minutes optimal |
| Image size | 1200x627 for links |
| Best posting times | Tue-Thu, 8-10am |
| Hashtags | 3-5 relevant |
| CTA | In post text |

**LinkedIn Post Template**:
```
[Hook: Problem or insight]

[2-3 sentences of value]

[Specific data or result]

[CTA: Link or question]

#WebGL #InteractiveDesign #DigitalExperience

### 5. Engagement Strategy

#### Engagement Response Framework

| Type | Response Time | Tone |
|------|---------------|------|
| Question | <1 hour | Helpful, informative |
| Compliment | <2 hours | Grateful, personalized |
| Complaint | <30 min | Empathetic, solution-focused |
| Mention | <1 hour | Acknowledge, engage |
| Share | <2 hours | Thank, amplify |

#### Community Building Tactics

| Tactic | Implementation | Frequency |
|--------|----------------|-----------|
| Reply to all comments | Personalized responses | Ongoing |
| User content reshare | Feature with credit | Weekly |
| Ask questions | Polls, open questions | 2-3x/week |
| Industry engagement | Comment on relevant posts | Daily |
| Live sessions | Q&A, demos | Monthly |

### 6. Viral Content Strategy

#### Shareability Factors

| Factor | Implementation |
|--------|----------------|
| Emotion | Awe, surprise, curiosity |
| Value | Educational, useful |
| Identity | Industry pride |
| Timeliness | Current trends, news |
| Social Currency | Insider knowledge |

#### Viral Content Templates

**Hook Types**:
1. **Curiosity Gap**: "Most companies get this wrong about WebGL..."
2. **Contrarian**: "Interactive websites are overrated. Here's why (thread)..."
3. **Behind the Scenes**: "This took 6 months to build. Here's the 30-second version..."
4. **Data-Driven**: "We analyzed 100 WebGL sites. The results surprised us..."
5. **Tutorial**: "How to create this effect in 5 steps..."

LAUNCH CAMPAIGN TIMELINE

│

│   ├── Team stories

├── LAUNCH DAY
│   ├── Full reveal
│   ├── Multiple posts

│

│   ├── User reactions
│   ├── Deep dives

│

    ├── User stories

```

### 8. Measurement & Analytics

#### Key Social Metrics

| Metric | Definition | Target |
|--------|------------|--------|
| Engagement Rate | (Likes+Comments+Shares) / Reach | >3% |
| Click-Through Rate | Clicks / Impressions | >1% |
| Share Rate | Shares / Reach | >0.5% |
| Video Completion | Completed views / Views | >25% |
| Follower Growth | Net new followers | >5%/month |

#### Attribution Tracking

| Element | Implementation |
|---------|----------------|
| UTM Parameters | All links tagged |
| Social-specific landing | Customized experience |
| Conversion tracking | Pixel implementation |
| Social listening | Brand mentions tracking |
