┌─────────────────────────────────────────────────────────────────────────────┐
│ KEY COMPONENTS & RESPONSIBILITIES                                          │
└─────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────┐
│   AuthNotice         │  • Shows sign-in prompt
│                      │  • Handles navigation with returnTo
│   autoNavigateToLogin│  • Encodes current URL as returnTo parameter
└──────────────────────┘

┌──────────────────────┐
│   ProtectedRoute     │  • Guards protected routes
│                      │  • Builds returnTo from location
│   Checks auth status │  • Redirects to login if not authenticated
└──────────────────────┘

┌──────────────────────┐
│   LoginPage          │  • Handles authentication
│                      │  • Multi-tier redirect resolution:
│   resolveRedirect    │    1. URL param returnTo
│   Target()           │    2. sessionStorage
│                      │    3. location.state
│                      │    4. Default to /
│                      │  • Infinite loop prevention
│                      │  • "Continue as Guest" option
└──────────────────────┘

┌──────────────────────┐
│   AuthContext        │  • Global auth state
│                      │  • Session expiry handling
│   handleUnauthorized │  • Saves returnTo to sessionStorage
│                      │  • Stores error messages
│                      │  • Navigates to login
└──────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│ REDIRECT RESOLUTION PRIORITY                                                │
└─────────────────────────────────────────────────────────────────────────────┘

  Priority 1: URL Query Parameter
  ├─ /auth/login?returnTo=%2Fassessment%2Fstart
  ├─ Most explicit and debuggable
  └─ Safety: Rejects /auth/login, /auth/register

  Priority 2: SessionStorage
  ├─ sessionStorage.getItem('auth:postLoginRedirect')
  ├─ Set by auth:unauthorized event
  └─ Safety: Rejects any /auth/* path

  Priority 3: Location State
  ├─ location.state.from (React Router)
  ├─ Passed by ProtectedRoute
  └─ Safety: Rejects any /auth/* path

  Priority 4: Default
  └─ Navigate to / (home page)


┌─────────────────────────────────────────────────────────────────────────────┐
│ SECURITY FEATURES                                                           │
└─────────────────────────────────────────────────────────────────────────────┘

  ✓ Infinite Loop Prevention
    • Filters returnTo pointing to /auth/login or /auth/register
    • Prevents endless redirect cycles

  ✓ XSS Prevention
    • Proper URL encoding with encodeURIComponent()
    • Safe parameter handling

  ✓ Open Redirect Prevention
    • Only relative URLs accepted (starting with /)
    • Absolute URLs should be filtered

  ✓ Graceful Degradation
    • SessionStorage fallback if unavailable
    • Multiple fallback layers for robustness
