## Test Procedure

### Per-Device Testing Steps
1. [ ] Clear browser cache and data
2. [ ] Close all other apps/tabs
3. [ ] Connect to same network for consistency
4. [ ] Load cornrevolution.resn.global
5. [ ] Start performance monitoring
6. [ ] Measure initial load time
7. [ ] Scroll through entire experience
8. [ ] Record FPS during idle and scrolling
9. [ ] Take screenshots
10. [ ] Document any issues or anomalies
11. [ ] Test touch/mouse interactions
12. [ ] Test in both portrait/landscape (mobile/tablet)
